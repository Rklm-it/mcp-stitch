# mcp-stitch

Google Stitch (генерация экранов и дизайна UI) коннектором в claude.ai и
Claude Code — через хаб [nexus-mcp](https://github.com/Rklm-it/nexus-mcp).

## Зачем прослойка, если у Stitch есть API

У Stitch есть API-ключ и официальный MCP-сервер Google:
`https://stitch.googleapis.com/mcp`. Он принимает ключ только заголовком
`X-Goog-Api-Key`, а коннектор claude.ai умеет передать лишь адрес: ни
заголовков, ни входа OAuth у Stitch для коннекторов нет.

Поэтому хаб отдаёт `https://<хаб>/stitch/mcp/<секрет>` и проксирует в Stitch,
подставляя ключ сам. Своей логики в прослойке нет: все инструменты Stitch
(проекты, экраны, генерация, правка, варианты, дизайн-системы) — те же самые,
что у Google. Ключ не покидает хаб.

## Установка

1. Ключ: [stitch.withgoogle.com](https://stitch.withgoogle.com) → аватар
   справа вверху → **Stitch settings** → **API key** → **Create key**.
2. На хабе (по SSH, root):

   ```bash
   curl -fsSL https://raw.githubusercontent.com/Rklm-it/mcp-stitch/main/install.sh | sudo bash
   ```

   Установщик спросит ключ (ввод скрыт), проверит его живым запросом в Stitch,
   поднимет маршрут в Caddy хаба, проверит его сквозь хаб и напечатает ссылку.
3. Ссылку — в claude.ai: **Настройки → Коннекторы → Add custom connector**.
   Тот же коннектор появится и в Claude Code, открытом с этого аккаунта.

## Команды

| Команда | Что делает |
|---|---|
| `mcp-stitch` | состояние и ссылка коннектора |
| `mcp-stitch url` | только ссылка |
| `mcp-stitch set-key` | сменить ключ (ссылка остаётся прежней) |
| `mcp-stitch check` | сквозная проверка: хаб → Stitch, как ходит claude.ai |
| `mcp-stitch rotate-secret` | новый секрет в ссылке, старая перестаёт работать |
| `mcp-stitch off` | убрать маршрут и стереть ключ с хаба |
| `mcp-stitch update` | обновить команду с GitHub |

## Безопасность

- Ключ хранится в одном файле: `/etc/caddy-nexus-mcp/sites/mcp-stitch.caddy`
  (0600, root). В командную строку он не попадает (его видно в `ps`): в curl
  идёт заголовком из временного файла, в команду — с терминала.
- Ссылка коннектора с 40-символьным секретом и есть доступ к Stitch от вашего
  имени. Её не пересылать. Утекла — `mcp-stitch rotate-secret` (и заменить в
  claude.ai). Ключ отзывается в Stitch settings.
- Прокси снимает с запроса `Authorization` и `Cookie`, поэтому заголовки
  claude.ai до Google не доходят.
- Маршрут перед применением проверяется `caddy validate`. Не принят — файл
  возвращается байт в байт: сломанный маршрут уронил бы весь хаб
  (коннекторы, чат приложения, реле нод).
- Генерации Stitch ограничены квотой аккаунта Google (около 350 в месяц
  бесплатно). Одна генерация идёт минуты: это нормально, а не зависание.

## Переезд хаба

Маршрут лежит в каталоге Caddy хаба, поэтому едет в бэкапе и при переезде
(`nexus-hub` → «Переезд на другой впс»). Если у нового хаба другой домен,
ссылка меняется: `mcp-stitch url` → заменить в claude.ai. Саму команду на
новом сервере поставить заново тем же `install.sh`: приехавший маршрут он
увидит, ключ спрашивать не станет и только проверит Stitch сквозь новый хаб.
